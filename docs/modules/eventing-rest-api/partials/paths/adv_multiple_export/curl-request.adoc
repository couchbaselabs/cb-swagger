= Example HTTP Requests

.View all function definitions
====
.curl request
[source,sh]
----
curl -X GET "http://$USER:$PASSWORD@$HOST:8096/api/v1/export"
----
====

.Save all function definitions to file
====
.curl request
[source,sh]
----
curl -X GET "http://$USER:$PASSWORD@$HOST:8096/api/v1/export" \
  -o array_of_functions.json
----
====
